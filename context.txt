A floor game for the YC Startup Internship Expo.

Event: Saturday Aug 15, 2026, Dogpatch HQ, San Francisco

Event id: evt-mqy1btILJGEqgAD
~1,348 going on Luma. Confirmed guests with LinkedIn: 795.
Ticket key: tPX7lX

Product is TWO LOOPS, one token wallet. Do not add student-vs-company Groq
fights (API cost). Do not fold the Nowadays dining challenge into this game.

1) LARP BATTLE (people vs people)
   Confirmed expo guests only (~795). Each person is pre-scored ONCE (O(n)).
   A fight compares two flex_scores and stitches a templated compliment + roast.
   No Groq required for v1. Optional live roast later if a Groq key is pasted.

2) SLOTS (company quiz as the other loop)
   Company intel becomes quiz/content, not Groq opponents.
   Question bank already exists (was built for a Crossy Road prototype).
   Slots are the likely v1 instead of Crossy Road physics.
   Spin is a token sink (unlocks / rerolls / cosmetics). Not internships, not fake merch.

Not v1:
- Company matching via Groq
- Pairwise precompute (~315k) or vs-51-companies (~40k)
- Wiring extra expo APIs for flavor
- Crossy Road physics if slots ship first
- Fight UI / slot UI / /api/larp  (NONE OF THIS IS BUILT YET)

flex_score (0-100) is who wins. larp_index is a roast badge, not the winner.
Battle: higher flex_score wins. Tie -> lower larp_index, then name.
Deterministic seed from sorted ids. Zero API cost after preload.
